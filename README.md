# 瞬间 · 烟火实验室

一个无第三方依赖的网页版烟花模拟器，使用 Canvas 2D 实时绘制粒子。

## 使用

直接在浏览器中打开 `dist/index.html` 即可离线使用。也可以运行 `node server.cjs`，然后访问 http://127.0.0.1:4173。

- 点击夜空或按空格发射一组烟花；`F` 切换全屏。
- 十四种形态：经典菊花、垂柳、星环、爱心、棕榈、双重奏、闪耀星雨、裂变花火，以及五角星、土星光环、旋涡、五瓣花、花束连爆、流萤飘落。
- 默认混合烟花秀：可多选样式和颜色，每一发单独随机。也可切换固定样式与单色。
- 随机大小支持设置最小与最大值；随机换色逐发换色，多彩变色让同一朵烟花双色渐变。
- 新增二次爆炸、分裂子火花、星芒、扩散光圈与局部夜空照亮，可调整光效强度。
- 可调大小、颜色、粒子密度、每次发射数量和自动燃放间隔。
- 更多参数：拖尾长度、重力、风向与风力。
- 自动燃放、清空、重置和可选音效。音效默认关闭，首次点击音效开关会立即试听。
- 爆炸使用六段 CC0 烟花录音轮换，保留自然尾声；移除了扫频正弦低音、固定间隔连击和人工回声。细碎火花只播放较轻的录音尾部，升空气流单独低音量合成。
- 录音随页面内嵌，可离线播放。保留试听按钮、音量滑块和实时输出电平，关闭音效会立即停止当前声音。
- 桌面侧栏与手机纵向布局；系统启用减少动态效果时，默认关闭自动燃放。
- 根据设备选择默认配置：电脑每轮 4 发、密度 180、间隔 1.5 秒、大小 55–130%；手机/平板每轮 2 发、密度 100、间隔 2.2 秒、大小 55–115%。光效强度均为 85%，保留全部形态、渐变、辉光、拖尾和爆闪。
- “设备与画质”可手动选择电脑或手机档位。切换档位应用对应默认参数，保留当前音量和自动燃放开关；重置和一键混合使用当前档位。缩小电脑窗口不会误判为手机，旋转手机也不会重置自定义参数。

样式、颜色、大小、密度、重力和风力应用于下一批烟花；拖尾、光效和音量立即生效。关闭自动燃放时，已经发射的烟花会继续播放，点击清空即可立即移除。每批最多 10 发，密度控制主体粒子数（最多 300）；内层、闪光及裂变可生成额外粒子。电脑初始粒子预算 6500、待发和上升烟花合计上限 40；手机分别为 1800 和 16。预算收紧后已有烟花自然消退，仅限制新粒子，避免突然抹掉画面。

## 性能

- 同色、近似透明度的拖尾合并为批次描边，星芒也合并绘制。普通场景每颗星点都有辉光；极密集场景合并核心星点、减少重叠光晕，保留全量星点、爆闪及整体照亮，拖尾改用速度近似。按稳定种子选取光晕，避免闪烁。
- 轨迹使用 20 个采样点的 Float32Array 环形缓存，过期后回收复用；移除逐帧轨迹对象分配和数组 shift。两段渐隐拖尾各采样三点，保留弯曲路径。
- 手机画布最高 1.5× 像素密度，电脑最高 2×；不影响文字、控件清晰度，不锁帧。
- 连续四个半秒统计窗口低于 45 FPS 或 CPU 帧耗时超过 18 ms 时降低一档，连续十六个健康窗口逐档恢复。手机精度下限 1×、粒子预算下限 1000；电脑分别为 1.5× 和 3600。不会改动用户设置的光效强度或颜色。
- 页签隐藏、手机滚动至夜空完全离屏时暂停模拟；返回后继续，不补发积压烟花。
- Canvas 优化参考：[MDN — Optimizing canvas](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API/Tutorial/Optimizing_canvas)。

## 文件

- `dist/index.html`：中文界面与语义化控件。
- `dist/config.js`：设备识别、两套参数和渲染预算。
- `dist/styles.css`：响应式深色布局。
- `dist/engine.js`：按时间步长更新的烟花物理与绘制。
- `dist/audio.js`：用户手势启用、录音解码、播放、混音和输出电平检测。
- `dist/audio-assets.js`：六段内嵌烟花录音，由 `node scripts/embed-audio.cjs` 生成。
- `assets-source/fireworks/CREDITS.md`：录音来源、CC0 许可与处理说明。
- `dist/app.js`：多选与随机参数、交互、键盘操作及可选 WebMCP 接口。

无需安装依赖或执行构建。更新 Cloudflare Pages 时上传完整的 `dist` 文件夹，必须包含新增的 `config.js`。HTML 中为修改过的脚本和样式添加版本参数，避免继续使用旧缓存。

## 验证

运行 `node tests/verify.cjs` 检查随机选择范围、十四种形态的寿命和轨迹、连爆、裂变、设备识别、自动降档/恢复、轨迹复用、两端负载上限和清空。运行 `node tests/benchmark.cjs [旧版engine.js路径]` 比较固定种子的 Canvas 绘制命令数量；这不是手机 GPU 或 FPS 测试。音效需在浏览器中点击开启或试听；输出电平代表已生成声音信号，不代表浏览器标签页、系统或扬声器一定未被静音。
